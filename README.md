# MindMatch – AI Peer Learning Platform

MindMatch is an AI-driven peer learning platform designed to connect students based on skills, interests, and learning preferences. It helps users find suitable study partners and enables skill-based collaboration through intelligent matching and recommendation logic.

## Features
- AI-based matching of students using skills, interests, and learning preferences
- Personalized study partner recommendations
- Skill-based collaboration and peer learning support
- Scalable platform design for user interaction and future growth

## Tech Stack
- Python
- React + Vite
- MongoDB
- NumPy
- Pandas
- Machine Learning

## Outcome
Developed a full-stack peer learning platform that combines recommendation logic, user interaction, and data-driven matching to improve collaborative learning experiences.
